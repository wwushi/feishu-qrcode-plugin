# 飞书多维表格二维码生成插件

这是一个飞书多维表格的字段捷径插件，可以将表格中任意字段的内容生成高质量二维码，并支持丰富的个性化配置。

## 技术栈

- Node.js：开发环境
- TypeScript：类型安全的开发语言
- qrcode：用于生成二维码
- 飞书多维表格插件SDK：与飞书平台交互

## 功能介绍

### 主要功能

✅ **基本二维码生成**：将文本或链接转换为二维码
✅ **彩色配置**：自定义二维码前景色和背景色（HEX色值）
✅ **尺寸调整**：支持三种尺寸选择（小: 300px, 中: 400px, 大: 500px）
✅ **容错率选择**：支持L、M、Q、H四个等级的容错率
✅ **智能颜色修复**：自动修复不完整的颜色值

### 技术特点

- **类型安全**：使用TypeScript开发，确保代码质量和稳定性
- **高质量生成**：使用成熟的qrcode库，确保生成的二维码清晰可扫描
- **轻量高效**：插件体积小，执行速度快，不影响表格性能
- **隐私安全**：所有处理都在服务端完成，不收集或传输任何用户数据
- **容错设计**：完善的错误处理和参数验证，确保插件稳定运行

## 安装方法

1. 克隆或下载本项目到本地
2. 进入项目目录，安装依赖：
   ```bash
   npm install
   ```
3. 生成插件包：
   ```bash
   npm run pack
   ```
   执行后将在 `output` 目录生成插件包文件
4. 登录飞书开发者后台，创建新的插件
5. 上传生成的插件包文件
6. 在飞书多维表格中启用该插件

## 使用方法

1. 在飞书多维表格中创建一个新的字段
2. 选择「字段捷径」类型
3. 在字段捷径配置中选择本插件
4. 配置参数：
   - **二维码内容**：输入要生成二维码的文本或链接
   - **二维码前景色**：自定义二维码颜色（HEX色值），默认黑色
   - **二维码背景色**：自定义二维码背景色（HEX色值），默认白色
   - **二维码尺寸**：选择二维码尺寸（小/中/大）
   - **容错率**：选择二维码容错率等级
5. 保存配置后，表格会自动生成对应的二维码

## 注意事项

- 二维码内容长度建议不超过1000个字符
- 颜色值请使用有效的HEX格式（如 #000000）
- 生成的二维码会以附件形式返回，符合飞书官方要求
